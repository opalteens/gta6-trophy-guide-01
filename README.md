Leonida Nights — offline GTA 6 trophy guide and tracker: all 55 official PS5 trophies (1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden; exactly 1 missable) with own-words guides, a 3-stage roadmap to platinum, spoiler-safe blur, and local progress tracking.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no network requests, no build step, progress stays in your browser.
